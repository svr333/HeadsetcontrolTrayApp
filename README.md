# Audeze Maxwell Tray App
Small app with inspiration from [This Repo](https://github.com/DByte308/audeze-maxwell-battery) for a small KDE Plasma Tray icon that shows the battery of your Audeze Maxwell headset.

## Requirements
- [Headsetcontrol](https://github.com/Sapd/HeadsetControl)
- Python, Python-Pillow

This app was made with qwen3.6-27B.
